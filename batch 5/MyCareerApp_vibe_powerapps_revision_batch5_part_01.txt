Concern 1: Make the Homepage "Status Kamu" section more colorful using the badge style from the fixed app.
- The current Status Kamu cards are too plain: each value is large black text on an otherwise empty white card.
- Reuse the compact colored status badges from MyCareerApp/fixed/S1_Homepage.yaml. The user likes that palette and visual treatment.
- Keep the overall section professional and readable. Use white cards with subtle borders/shadows, while placing the dynamic result inside a colored pill/badge.
- Each status item should contain:
  - A readable muted-gray label at the top.
  - A compact colored badge below it.
  - Badge height around 28-32 px.
  - Horizontal padding around 10-12 px.
  - Semibold text.
  - Corner radius around 6-14 px.
  - Badge width based on its content rather than filling the entire card.
- Do not color the full card with strong colors. Use soft badge backgrounds so the section remains balanced.

Use the fixed-app badge palette:
- Success/completed:
  - Text: RGB(16, 124, 16).
  - Fill: RGB(223, 246, 221).
- Warning/action required:
  - Text: RGB(122, 70, 0).
  - Fill: RGB(255, 244, 206).
- Neutral/not started/period ended:
  - Text: RGB(96, 94, 92).
  - Fill: RGB(243, 242, 241).
- Informational/available data:
  - Text: RGB(0, 78, 140).
  - Fill: RGB(222, 236, 249).
- These soft blue values are acceptable. Do not use the bright cyan/turquoise selection color prohibited in earlier revisions.
