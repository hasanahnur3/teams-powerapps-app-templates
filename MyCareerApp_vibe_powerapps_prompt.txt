Build a Microsoft Power Apps canvas app named "MyCareerApp".

The app is an internal employee career development and talent management system for an organization. It helps employees maintain their career profile, submit performance reviews, record mentoring and coaching activities, manage Individual Development Plans (IDP), upload mentoring checklist evidence, and lets managers, leaders, coaches, mentors, and admins monitor employee progress.

Use a clean, professional, enterprise style:
- Primary color: dark navy blue.
- Background: light gray.
- Cards and tables: white, subtle borders, 8 px radius.
- Typography: Open Sans or similar.
- Layout should be responsive for desktop and tablet.
- Use clear Indonesian labels because the users are Indonesian employees.
- The app name shown in top bars should be "MyCareerApp".

Core user roles:
1. Employee / Pegawai
   - Can view and edit their own profile.
   - Can create and view their own Performance Review.
   - Can view coaching/mentoring records involving them.
   - Can create and edit their current-year IDP.
   - Can view prior-year IDP in read-only mode.
   - Can create and manage their own Checklist Mentoring.

2. Line Manager
   - Can review Performance Review records for employees assigned to them.
   - Can open review details.

3. Mentor / Coach
   - Can create coaching and mentoring sessions.
   - Can manage action items from career coaching sessions.
   - Can view mentee coaching records.

4. Pimpinan / Leader
   - Can select a subject employee from an employee list.
   - Can view that employee's profile, IDP, performance review, coaching, and checklist data in context.
   - Leader view should use global subject employee context, not the current logged-in user's NIP.

5. Admin
   - Can open a Monitoring Mentoring menu.
   - Can choose a year.
   - Can see all employees and whether each employee has submitted Checklist Mentoring for the selected year.
   - Can click rows that are already submitted and open the Checklist Mentoring detail in read-only monitoring mode.

Main data tables and important fields:

1. Pegawai
   - Title: employee NIP as text.
   - NIP: employee NIP, if present.
   - Nama: employee full name.
   - Satker: work unit.
   - Jabatan: job title.
   - Pangkat: grade/rank.
   - LastUpdated: date.
   - NilaiKinerja: numeric average performance score.
   - IsPegawai: boolean.
   - IsLineManager: boolean.
   - IsCoach: boolean.
   - IsPimpinan: boolean.
   - IsAdmin: boolean.

2. PerformanceReview
   - Title.
   - NIP.
   - Tahun.
   - Semester.
   - Tanggal.
   - LineManagerNIP.
   - FotoBukti or supporting evidence.
   - Other review fields as needed.

3. CoachingKarir
   - Title.
   - MenteeNIP.
   - MentorNIP.
   - Tanggal.
   - Catatan.
   - Other coaching fields as needed.

4. ActionItem
   - Title.
   - CoachingID.
   - Kategori.
   - Tipe.
   - Detail.
   - Other action item fields as needed.

5. CoachingTematik
   - Title.
   - MenteeNIP.
   - MentorNIP.
   - Tanggal.
   - Topik.
   - Catatan.

6. IDP
   - Title.
   - ID.
   - NIP.
   - Tahun.
   - Kategori.
   - Tipe: choice column.
   - Detail.
   - Target: TW1, TW2, TW3, TW4.
   - Status: Rencana, Proses, Selesai, Dibatalkan.
   - Modified.

7. ChecklistMentoring
   - Title.
   - ID.
   - NIP.
   - Tahun.
   - MentorNIP.
   - Status: Lengkap or Belum Lengkap.
   - PersonalStatementFile: image/file.
   - CareerPlanFile: image/file.
   - BuktiUploadFile: image/file.
   - Created.

8. Profile detail tables
   Use separate tables for employee career profile details:
   - Profil_Pendidikan: NIP, Jenjang, Universitas, ProgramStudi, TahunLulus.
   - Profil_SertifikasiTier1: NIP, NamaSertifikat, Penerbit, TglTerbit, TglBerakhir, NoSertifikat.
   - Profil_SertifikasiTier2: same structure as Tier 1.
   - Profil_PMK: NIP, TrainingName, Penyelenggara, StartDate, CompletionDate, JenisPMK, Tipe, Negara.
   - Profil_KumMengajar: NIP, NamaIHT, TanggalPelaksanaan.
   - Profil_Penugasan: NIP, StartDate, EndDate, PIC, NamaPenugasan, Deskripsi.
   - Profil_Prestasi: NIP, Jenis, Level, NamaPrestasi, DetailPrestasi, Tanggal.
   - Profil_Kepanitiaan: NIP, NamaKepanitiaan, Posisi, Institusi, UraianTugas, Produk, StartDate, EndDate.
   - Profil_Plt: NIP, JabatanPlt, UnitKerja, PeriodeMulai, PeriodeSelesai, NoSK, Skor, Catatan.

Global variables / app state:
- gblCurrentNIP: current logged-in employee NIP.
- gblSubjectNIP: selected employee NIP when leader/admin is viewing another employee.
- gblPimpinanView: true when viewing another employee as leader.
- gblSelectedChecklist: selected ChecklistMentoring record.
- gblChecklistEditMode: true when editing an existing checklist.
- gblChecklistAdminView: true when admin opens checklist detail from Monitoring Mentoring; this makes detail read-only and hides Edit/Delete.
- gblSelectedIDP: selected IDP record.
- gblIDPEditMode: true when opening an existing IDP.
- gblIDPReadOnly: true when opening non-current-year IDP.
- gblSelectedCoachingKarir, gblSelectedCoachingTematik, gblSelectedPR: selected records for detail screens.

Home screen:
- Show a top bar with app name.
- Show "Status Kamu" cards:
  - Performance Review Q1 status for current year.
  - Performance Review Q2 status for current year.
  - Last Career Coaching status.
  - IDP current year count.
- Show menu sections based on role:
  - MENU PEGAWAI: Profil Pegawai, Mentoring, Performance Review, Coaching Karir, Coaching Tematik, IDP.
  - MENU LINE MANAGER: Performance Review.
  - MENU MENTOR: Coaching Karir and Coaching Tematik.
  - MENU PIMPINAN: Daftar Pegawai.
  - MENU ADMIN: Monitoring Mentoring.

Employee profile:
- Screen title: Profil Pegawai.
- Show identity: Nama Pegawai, Satuan Kerja, NIP, Jabatan, Pangkat, Tanggal Pengisian.
- Show quantitative section:
  - Nilai Kinerja Rata-Rata 5 Tahun.
  - Masa Dinas Pangkat.
- Show career profile sections as tables:
  - Pendidikan.
  - Sertifikasi Tier 1.
  - Sertifikasi Tier 2.
  - PMK / Program Meningkatkan Kompetensi.
  - Kum Mengajar.
  - Penugasan DN/LN, Penugasan Strategis atau lainnya.
  - Prestasi BI Wide atau lainnya.
  - Kepanitiaan / Proyek / Tim Kerja / Adhoc lainnya.
  - Plt / Penunjukan / Rangkap Jabatan / Penugasan Tetap.
- Each row can open an edit form when the current user owns the profile.
- In leader view, show the selected employee's data based on gblSubjectNIP.

Performance Review:
- Employee can see their own performance review records.
- Line Manager can see employee performance reviews assigned to them.
- Leader can view selected employee performance reviews.
- List should show Tahun, Semester, Tanggal, Line Manager, and an action/detail button.
- Detail screen should show review information and supporting evidence.

Career Coaching / Coaching Karir:
- Mentee list: shows sessions where MenteeNIP equals the active employee NIP.
- Coach list: shows sessions where MentorNIP equals current user NIP.
- Each record has date, notes, mentor/mentee, and action items.
- Detail screen shows coaching details and related action items.

Coaching Tematik:
- Similar structure to Coaching Karir.
- List should show Tanggal, Topik, Mentor, and action/detail.
- Form allows creating/editing thematic coaching sessions.

Individual Development Plan (IDP):
- Screen title: Individual Development Plan.
- Top section should show action items from the latest Coaching Karir session for the active employee.
- Include a "Lihat detail" link to the latest coaching detail when a session exists.
- Main table title: Daftar IDP.
- Table columns: Tahun, Kategori, Tipe, Last Edited, Target, Status.
- Do not show Detail/Deskripsi in the IDP table to avoid overlap.
- Filter IDP by the active employee NIP:
  - If gblPimpinanView is true and gblSubjectNIP is not blank, use gblSubjectNIP.
  - Otherwise use gblCurrentNIP.
- Sort by Tahun descending and ID descending.
- Current-year rows are highlighted.
- Clicking any IDP row opens the IDP form/detail screen.
- If the IDP year is the current year:
  - Fields are editable.
  - Save and Delete are available.
- If the IDP year is not current year:
  - Open as "Detail Individual Development Plan".
  - All fields are disabled/read-only.
  - Hide Save and Delete buttons.
  - Bottom button should say "Kembali".
- New IDP defaults to current year.
- Kategori is derived from selected Tipe:
  - S2, S3 -> Pendidikan (PTB).
  - Sertifikasi Tier 1, Sertifikasi Tier 2, PMK, Kum Mengajar -> Sertifikasi.
  - Penugasan DN/LN, Prestasi BI Wide, Kepanitiaan BI Wide, Plt/Penunjukan/Rangkap Jabatan/Penugasan tetap -> Exposure.

Checklist Mentoring:
- Employee screen title: Daftar Checklist Mentoring.
- Employee can add new checklist.
- List columns: Tahun, Mentor, Dibuat, Status, Aksi.
- Detail screen shows:
  - Pegawai.
  - Tahun.
  - Mentor.
  - Status.
  - Personal Statement image/file.
  - Career Plan image/file.
  - Bukti Upload image/file.
- Form fields:
  - Tahun.
  - Mentor.
  - Personal Statement upload.
  - Career Plan upload.
  - Bukti Upload upload.
- Status should be "Lengkap" when all three uploads exist, otherwise "Belum Lengkap".
- Current-year checklist can be edited/deleted by the owner.
- Previous-year checklist should be read-only if needed.

Admin Monitoring Mentoring:
- This is the admin menu reached from Home > MENU ADMIN > Monitoring Mentoring.
- Screen title: Monitoring Mentoring.
- Show a year selector at the top, defaulting to the current year.
- Show a table of all employees from Pegawai.
- Table columns:
  - NO.
  - NAMA PEGAWAI.
  - NIP.
  - CHECKLIST MENTORING [selected year].
- For each employee, check if there is a ChecklistMentoring record where:
  - ChecklistMentoring.NIP = Pegawai.Title.
  - ChecklistMentoring.Tahun = selected year.
- If a record exists:
  - Show green pill "Sudah Diisi".
  - Row is clickable.
  - Clicking row sets gblSelectedChecklist and navigates to Checklist Mentoring Detail.
  - Set gblChecklistAdminView = true.
- If no record exists:
  - Show yellow pill "Belum Diisi".
  - Row should not navigate.
- The detail screen opened from admin monitoring must be read-only:
  - Hide Edit button.
  - Hide Delete button.
- Show summary cards below the table:
  - Total Pegawai.
  - Sudah Diisi.
  - Belum Diisi.
  - Completion Rate = Sudah Diisi / Total Pegawai * 100%.

Pimpinan / Leader employee selection:
- Screen title: Daftar Pegawai.
- Let leader choose an employee.
- After selecting, set gblSubjectNIP and set gblPimpinanView true when opening employee-related modules.
- Available tabs/buttons:
  - Profil Pegawai.
  - IDP.
  - Performance Review.
  - Coaching Karir.
  - Coaching Tematik.
  - Checklist Mentoring.
- All selected-employee screens should use gblSubjectNIP instead of gblCurrentNIP.

Important UX rules:
- Use Indonesian labels for user-facing text.
- Empty states should be explicit:
  - "Belum ada data."
  - "Belum ada IDP di sistem."
  - "Belum ada checklist mentoring."
- Use success/error notifications after save/delete.
- Use confirmation before delete.
- Refresh the relevant data source after save/delete.
- Do not allow accidental edit/delete from admin monitoring detail view.
- Avoid overlapping columns in wide tables.
- In tables, make rows visually clean and easy to scan.

Navigation map:
- Home -> Profil Pegawai.
- Home -> Performance Review.
- Home -> Coaching Karir.
- Home -> Coaching Tematik.
- Home -> IDP.
- Home -> Checklist Mentoring.
- Home -> Daftar Pegawai for Pimpinan.
- Home -> Monitoring Mentoring for Admin.
- IDP list -> IDP add/edit/detail.
- Checklist list -> Checklist add/edit/detail.
- Admin Monitoring -> Checklist detail read-only.
- Pimpinan Daftar Pegawai -> selected employee profile/IDP/performance/coaching/checklist.
